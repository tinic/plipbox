# plipbox 0.6-multicast (fork release)

This is a paired firmware and SANA-II driver update based on plipbox 0.6. It
adds selective Ethernet multicast reception so an IPv6 stack can receive
neighbour-discovery traffic. The driver forwards SANA-II multicast joins and
leaves to the firmware's ENC28J60 hash filter; it does not turn on promiscuous
multicast. It also implements SANA-II `S2_MULTICAST` transmission and
`SANA2IOF_MCAST` receive flags. An exclusive promiscuous open now works for
stacks configured to receive all Ethernet traffic. These address the
[multicast/filter report on a1k.org](https://www.a1k.org/forum/index.php?threads/98301/).
This is a fork release, not an upstream 0.7 release. The embedded
firmware and driver version strings still report 0.6.

## Downloads

- `plipbox-0.6-multicast-nano-atmega328p.hex`: firmware for the Nano pinout
  and ATmega328P only. Do not flash it to an Arduino-2009-pinout or
  AVR-NET-IO board.
- `plipbox.device-0.6-multicast-m68000`: GCC/LTO SANA-II driver for 68000 and
  later Amigas. Copy it to `DEVS:Networks/plipbox.device` after backing up the
existing file and taking the interface offline.
- Install the driver under the exact name `plipbox.device`. Amiga Exec will
  not open the same binary renamed to another `.device` filename; the
  [name check](../../scripts/check-driver-install-name.sh) catches that mistake.
- `SHA256SUMS`: hashes of the two binaries.

**Use the firmware and driver together for IPv6 multicast.** The original
0.6 firmware does not install multicast memberships. Retain copies of your
working firmware and driver so you can recover if the board's bootloader,
pinout, or network setup differs. Flash only with the board disconnected from
the powered Amiga parallel port; follow the [firmware guide](../src/firmware.md)
for bootloader or ISP instructions. The HEX file is not an Amiga executable.

## What was verified

- Clean Nano firmware build: AVR-GCC 16.1.0 with LTO; 12,629 bytes flash and
  1,798 bytes static SRAM. The build's parallel-port timing check passed.
- Clean 68000 driver build: GCC 16.2.0b toolchain package revision 16.2.1
  with LTO; 9,464-byte binary. It also runs on later 68k CPUs.
- Live A3000/68030, Nano-class plipbox: the paired firmware and driver came
  online; IPv4 and IPv6 unicast pings succeeded. Direct SANA-II multicast
  joins accepted three group addresses and rejected a unicast address.
  An IPv6 all-nodes multicast ping reached the A3000 and it responded; the
  driver's multicast receive counter increased. An exclusive
  `FILTER=EVERYTHING` open came online, and a subsequent normal open worked.

The release provides only the board variant exercised live. Other plipbox
pinouts, bootloaders, and stacks have not yet had the same end-to-end test.
The exact third-party `mcastfilter` program in the linked forum thread could
not be obtained, so its full filter matrix has not been claimed as tested.
There is no in-band firmware update or hardware reset command. Taking the
interface offline and online can re-establish a session, but recovery from a
wedged adapter may require cycling its separate power supply.
